# ⭐ FrostStars Telegram Bot

FrostStars — Telegram orqali topshiriqlar bajarish, referal orqali bonus olish va ichki Stars balansidan foydalanish imkonini beruvchi bot.

## ✨ Funksiyalar

- ⭐ Vazifalar bajarib bonus olish
- 👥 Referal tizimi
- 📊 Foydalanuvchi statistikasi
- 💳 Gift olish
- 🏆 Reyting
- 👑 Admin Panel
- 📢 Kanalga obuna vazifalari
- 💾 SQLite ma'lumotlar bazasi
- ⚙️ Mukofotlarni admin panel orqali boshqarish

## 🛠 Texnologiyalar

- Python
- python-telegram-bot
- SQLite
